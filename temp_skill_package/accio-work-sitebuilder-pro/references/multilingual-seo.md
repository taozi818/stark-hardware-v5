# Multilingual SEO/GEO Rules

## URL Structure

/en/product-name
/ar/product-name
/es/product-name

## SEO Requirements

Each language must have:
- Independent title
- Independent meta description
- hreflang tags
- Localized keywords
- Language-specific schema

## Market Focus

English:
Global buyers

Arabic:
UAE, Saudi Arabia, Middle East

Spanish:
Mexico, Spain, Latin America
